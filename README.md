# Amr Eslim - Portfolio

My personal portfolio website, designed with an Operating System and Terminal theme to reflect my background in Embedded Systems, C++, and Linux.

It features a command-line interface and system-monitor visuals to present my skills and projects in a format that feels at home for system engineers.

## Features

- **Terminal-Themed Interface**: Navigate content using a familiar command-line style or standard scrolling.
- **System Aesthetic**: Visuals inspired by boot sequences, hardware diagnostics, and specialized industrial tools.
- **Standard Web Tech**: Built with React and CSS, giving the look and feel of a system interface while running as a standard web application.

## Quick Start

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run locally**:
    ```bash
    npm start
    ```
    View at [http://localhost:3000](http://localhost:3000).

## Customization

The site content (bio, projects, skills) is managed via JSON files in `src/translations/`, allowing for easy updates without modifying the source code.
